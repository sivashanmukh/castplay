castplay

An asciicast player that runs where asciinema-player can't: no WebAssembly, no CDN stylesheet, no network at runtime. ~12 KB of plain JavaScript, with play, pause, seek and speed. Paste it into a single HTML file and a recorded terminal session becomes playable.

Install

npm i castplay

<script src="https://cdn.jsdelivr.net/npm/castplay@0/castplay.js"></script>

Use

<link rel="stylesheet" href="castplay.css">

<div data-castplay="cast-1"></div>
<script type="application/json" id="cast-1">
  [{"version":2,"width":80,"height":24},[0.1,"o","hello\r\n"]]
</script>

<script src="castplay.js"></script>
<script>castplay.auto()</script>

Why it exists

asciinema-player needscastplay
WebAssembly.instantiateplain JS, no eval of any kind
its stylesheet from a CDN or your originone small CSS file you can inline
~207 KB JS + 44 KB CSS~12 KB + 2 KB, both inlineable
a URL to fetch the recordingthe recording sits in the page

Use asciinema-player wherever those are fine — it is a real VT emulator and it is better. Use this for a strict-CSP page, a single self-contained .html, an LLM-generated artifact, or an offline docs bundle.
